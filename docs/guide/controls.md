# Controls

These workspace shortcuts work in the native Mac companion. A browser may reserve some Command shortcuts.

| Shortcut | Action |
| --- | --- |
| Command + K | Find a floor, or run an action from the Actions group (`Boards: …` and `Factory: …` open each Boards and Factory tab) |
| Shift + Command + 1–9 / 0 | Switch to floors 1–10 |
| Command + Plus / Minus | Next or previous floor (Mac app only) |
| Command + 1–8 | Choose a pane layout |
| Command + Enter | Maximize or restore the focused pane |
| Command + Left / Right | Switch panes |
| Command + Up / Down | Switch workers |
| Command + N | Hire into the focused pane |
| Command + B | Open the Whiteboard |
| Command + I | Open Boards |
| Command + O | Open the Orchestrator |
| Command + Comma | Open Settings |
| Command + Backslash | Toggle and focus the sidebar |
| Command + W | Close the focused pane in the Mac app |
| Shift + Command + W | Open Send home for the focused worker |
| Command + Q | Close the Mac window to the menu bar |
| Option + Command + Q | Quit the Mac app |
| Escape | Close a dialog; in a terminal, send Escape to the CLI |

Right-click a worker or shell in the sidebar for workspace, worker, copy and dismissal actions. Shift + F10 opens the same menu by keyboard. Closing a pane does not stop its worker.

In the Factory window, ⌘P goes to a file in Files. In a terminal, ordinary typing, Control shortcuts, Option and Escape belong to the CLI. Permission prompts are not approved automatically.
